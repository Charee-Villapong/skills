# stop-ai-slop-jp

日本語の文章から、AI 特有の不自然な表現を取り除くためのチェック用スキルです（日本語版）。

ありがちな言い回しや過剰な整形のパターンを一覧化し、下書きの点検に使います。

## ツール

### scripts/slop_check.py（記号と語彙の機械検出チェック）

下書きテキストを入力として、「クイックチェック」の記号レベル・語彙レベルの項目を数えます。検出項目がゼロ、または各項目が上限以内なら通過（終了コード0）、上限を超えた項目があれば一覧を出して終了コード1で止まります。

```bash
python3 scripts/slop_check.py 下書き.txt
```

上限はモジュール定数が正本で、`--sugiru-limit` などで変更できます。テストは `tests/test_slop_check.py` です。
