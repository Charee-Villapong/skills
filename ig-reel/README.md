# ig-reel

Instagram リールを企画から原稿まで作成するスキルです。

フックの候補出し、読み上げ原稿、画面に出すテキスト、秒単位のタイミング表までを通して作ります。

画面テキストの検査は `onscreen_check.py` が行います。各カードの語数（既定6語以内）、安全領域（1080x1920で y=230〜1440、右230pxは空ける）、フックカードがフレーム1にあるかをJSONで受け取り、違反を一覧で返します。違反があれば終了コード1で撮影準備へ進めません。

フック評価の下限ゲートは `hook_gate.py` が行います。`hookscore.py --json` の出力を入力として、最上位スコアが下限（既定50）以上なら台本作成へ進める（proceed）、未満なら止めてフックの作り直しを求めます（rewrite_hook）。下限は `--min-score` で変更できます。
