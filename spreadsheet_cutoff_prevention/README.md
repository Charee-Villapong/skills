# spreadsheet_cutoff_prevention

Google Sheets をスマホで見る前提で、文字の見切れを防ぐためのルール集です。

列幅と行高を実際の文字量から決める計算方法、新しい行を追加するときの書式・数式の付け忘れチェック、変更後の読み戻し検証までの手順を含みます。

列幅と日付書式の検査は `width_check.py` が行います。列幅メタデータとセル書式を JSON で受け取り、必要幅の不足と日付書式 `yyyy/mm/dd` の違反を一覧で返します。計算係数の既定値は sheet-writer tool 側の Measures（正本）と整合するようテストで担保しています。
