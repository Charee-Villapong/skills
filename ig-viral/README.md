# ig-viral

その分野で今伸びているリールを調査するスキルです。

各アカウントの規模に対してどれだけ伸びたかで順位付けし、使われているフックの型を分析して、自分の投稿に活かせる形でまとめます。

シグナル判定は `outlier_signal.py` が行います。収集表（TSV または JSON）を入力すると、各行について外れ値倍率（再生数 ÷ そのアカウントの中央値）と分類を JSON で返します。倍率が 3 倍以上ならシグナル、1.5 倍未満なら通常、その間はどちらでもありません。本人のフォロワー数を渡すと、規模が 10 倍の範囲外のアカウントは分類対象から外れます。中央値が欠けた行は分類せず、欠落として一覧に出します。しきい値は引数で変更できます。
