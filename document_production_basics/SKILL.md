# document_production_basics

資料（スライド・PDF・md のセット）を作る／直すときの当たり前を、指摘される前に済ませるためのスキル。

## 作業前
- 既存のページを先に全部見る。同種ページのキッカー／タイトル／フッターの型を把握してから作る。新しく足すページは、その型に合わせる。

## 当たり前チェック（納品前に全部通す）
1. **タイトル**：全ページにキッカー＋タイトルがある。同じ対象の続きページは、タイトルに対象の名前を含む（例：タスクフォースの話なら、どのページにも「タスクフォース」を含む）。
2. **全形式セット**：同じ資料の md／pptx／PDF はセットで更新する。1形式だけ直して終わらない。「PDFは現行維持」等の決定がある場合だけ、その決定に従う。
3. **検証は描き出しで**：文字列の有無でなく、描き出した画像で目視確認する。変更前後で全ページのテキストを比べ、対象外のページが無変更であることも確認する。
4. **詰め込まない**：フォントを縮めて詰め込まない。入らなければページを分ける。
5. **数字は原典で**：資料自身の集計を鵜呑みにしない。git・実ファイルで実測できるものは実測する。
6. **納品の形**：直したページの描き出し PNG を必ず添えて報告する。

## チェック用 tool
- `tools/deck_check.py <file.pptx>`：全スライドのキッカー／タイトルを一覧し、タイトルなし・タイトルの重複を flag 表示する（flag があれば終了コード1）。
- `tools/deck_check.py --diff <old.pptx> <new.pptx>`：スライドごとのテキストを比べて、変わったスライド番号だけを出す。
