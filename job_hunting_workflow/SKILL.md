# 転職活動ワークフロー（スカウト対応の一連の流れ）

転職活動（主にスカウトサービスのスカウト対応）を、受信から面談日程の確定まで一連の流れとして進めるための手順。実際のスカウト対応を通じて確立した進め方。

## 大原則
- **送信は必ず本人の承認後**。下書き→本人が確認・修正→承認→送信の順を守り、勝手に送らない（スルガ銀行の進め方と同じ）。
- **読み取りと送信は分ける**。内容確認だけを頼まれたら、返信の下書き送信・送信は絶対にしない。
- ログインは保存済みログイン（Secure Vault）を使い、パスワードはチャットで聞かない・書かない。ログインIDのヒントは本人のGmailアドレス。
- 本人が「頼んだ時だけ動く」と決めているので、通知が来ただけでは動かず、本人の指示を受けてから各ステップを進める。

## 手順
1. **スカウト・返信の検知**
   - 英語スカウトは専用cron（毎日12:00、専用サイドチャット「💼 スカウトメール」へ要約）が担当。それ以外は本人の声かけやGmail通知（例: スカウトサービスの「返信メッセージが届いています」）で気づく。
   - 通知メールに本文が含まれないことが多い。その場合は対象サイトにログインしてスレッド全文を読む（読み取りのみ）。

2. **内容の把握と提示**
   - 相手（担当者名・会社）、用件、提示条件、求められているアクションを整理して本人に伝える。
   - 初めての会社なら会社リサーチも添える: 設立時期・法人番号、資本金・資金調達、社員数、本社所在地、口コミの有無、年収レンジや雇用形態が提示されているか。本人の希望は「年収1000万円目安・安定した雇用（フリーランスは望まない）」なので、スタートアップ等のリスクは率直に添える。

3. **返信の下書きと送信**
   - 本人が方針（例: 「話を聞く」「面談はオンライン希望」）を決めたら、その内容で下書きを作り、本人に見せてから送信する。
   - **体裁チェック必須（2026-10-29 本人指示）**: 下書きを本人に見せる前と、送信する直前に、必ず体裁チェックを挟む。使うスキルは日本語用3本: natural-japanese（coji、仕事の日本語の主担当。~/workspace/custom-skills/natural-japanese/SKILL.md、lint.py による機械検出を含む）、natural-japanese-writing（日本語のAIっぽさ専用、~/workspace/custom-skills/natural-japanese-writing/SKILL.md）、stop-ai-slop-jp（書き手の不在・構造の癖、~/workspace/custom-skills/stop-ai-slop-jp/SKILL.md）。あわせて、マークダウン記号（** など）の混入を除去し、定型文の重ね掛けや「させていただきます」の連発を避け、受信者が見るプレーンテキストとして読み直してから提示・送信する。このチェックはメール作成・送信プロセスの必須ステップであり、省略しない。（英語用の humanizer / no-ai-slop は日本語用でないため 2026-10-29 に削除済み）
   - 送信後は送信済み文面を検証し、結果を報告する。
   - 一度伝えて相手が了承済みの条件（オンライン希望など）を、その後の返信で毎回繰り返さない。文面は簡潔に。

4. **相手から日程候補が来たら**
   - まずGoogleカレンダーを読み、候補枠と本人の予定の競合を先にチェックする（手術・休み取得日、締切当日、家族行事などは特に注意）。競合や懸念は候補提示のときに一緒に伝える。
   - 本人が枠を選んだら、カレンダーに面談予定を作成してブロックする（タイトルは「🤝 面談（会社名）」形式。色の指定がなければデフォルト）。
   - 返信は「選んだ枠でお願いする」文面を下書き→承認→送信。所要時間が候補枠より短い場合（例: 候補17:00-19:00・所要1時間）は開始時刻を明示して提案する。

5. **記録**
   - 進行状況（返信済み・候補日・確定日など）は MEMORY.md の該当エントリと、相手の人物ファイル（~/memory/people/）に更新する。
   - 面談が確定したら、その後のフォロー（御礼・次回連絡の有無）も本人の指示で同様に進める。
